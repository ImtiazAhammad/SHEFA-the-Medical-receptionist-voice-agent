# SHEFA Voice Commons: API contract for the web pages

Backend: `src/shefa/collector/` (FastAPI). Two apps:

* **Public app**, default `http://127.0.0.1:8100`, serves `src/shefa/collector/static/public/` at `/`
  and `/api/c/*`. This is what the tunnel exposes. Contributors only.
* **Private app**, default `http://127.0.0.1:8101`, serves `src/shefa/collector/static/private/` at `/`
  plus `/api/review/*` and `/api/admin/*`. Localhost only. (`serve --with-review` also mounts
  `/api/review/*` and the private pages under `/review/` on the public port, reviewer tokens only.)

All errors: HTTP 4xx/5xx with `{"error": {"code": "...", "message": "..."}}` (`message` is safe to
show; Bangla for contributor-facing audio rejections). Everything is UTF-8 JSON except clip upload.

## Public endpoints (contributor)

Auth for everything except the first four rows: headers `X-Cid` (contributor id), `X-Secret`
(contributor secret), `X-Speaker` (current speaker id). All three come from `POST /api/c/start`.

| Method and path | Body / query | Reply |
|---|---|---|
| `GET /health` | | `{ok, maintenance: "" \| "paused" \| "disk_low"}` |
| `GET /api/c/config?c=<campaign>` | | `{consent_version, consent_bn, consent_en, turnstile_site_key, min_clip_s, max_clip_s, settings:[{id,bn}], from_name, campaign, maintenance, progress, age_bands[], divisions[], voice_note: bool, impact_note: string}` |
| `POST /api/c/start` | `{consent:true, consent_version, campaign, from_name, device, turnstile}` | `{contributor_id, secret, delete_code, speaker_id, maintenance}`. `delete_code` is shown to the person once (format `AB12-CD34-EF56`). |
| `GET /api/c/progress` | | `{clips, minutes, speakers, goal_minutes}` |
| `GET /api/c/thanks` | | `{names: string[]}` (opt-in nicknames only) |
| `POST /api/c/speaker` | auth | `{speaker_id, delete_code}` (pass-the-phone: a new person on the same phone, with THEIR OWN delete code and profile) |
| `GET /api/c/cards?n=3&seen=id1,id2&kinds=booking,info` | auth | `{cards: Card[]}` |
| `PUT /api/c/clip/{clip_id}` | auth, raw audio body (see below) | `{ok, clip_id, duplicate, duration_s, snr_db}` or `422 {error:{code:"rejected"\|"unreadable", reason:"too_short"\|"too_long"\|"silent"\|"clipped"\|"unreadable"}}`, `409 duplicate`, `410 withdrawn`, `413 too_big`, `429 slow_down/daily_cap`, `503 paused` |
| `POST /api/c/profile` | auth, `{age_band, gender, division, nickname, credit_ok}` | `{ok}` (applies to the speaker in `X-Speaker`; all optional; unknown values are dropped) |
| `POST /api/c/delete` | `{delete_code}` | `{ok, deleted}` (only that person's clips) or 404 |
| `POST /api/c/room` | auth, `{card_id?}` | `{code, card, role:"caller"}` |
| `POST /api/c/room/join` | auth, `{code}` | `{code, role:"caller"\|"desk", card, state, sheet}` (`sheet` only for desk) or 404/409 |
| `GET /api/c/room/{code}` | auth | `{state, role, clips:[{id,role,turn,slot,duration_s,created_at}], partner_here, card, sheet}` |
| `GET /api/c/room/{code}/clip/{clip_id}` | auth | audio bytes (room members only) |
| `GET /q/{name}.wav` | | the agent's spoken question (16 kHz WAV) |
| `GET /voice-note` | | the founder's welcome note (`voice_note.m4a`/`.mp3`/`.ogg`/`.webm` in the data folder, in that order; iPhones need m4a or mp3), 404 if absent |

### Clip upload
`PUT /api/c/clip/{clip_id}` where `clip_id` is **32 lowercase hex chars generated by the phone**
(retries reuse the same id, so uploads are idempotent). Body: the audio bytes, preferably a 16 kHz
mono 16-bit PCM **WAV** (<= 450 KB, 0.6 to 14 s); WebM/Opus, Ogg or MP4/AAC from `MediaRecorder` are
accepted as a fallback. Headers: `X-Card`, `X-Step` (card and step id, from the card),
`X-Setting` (one of `config.settings[].id`), `X-Sha256` (hex of the body, optional but recommended),
`X-Room`, `X-Turn` for two-person calls (the server checks membership, 403 `no_room` otherwise, and decides the role itself). The server fills slot, kind,
question and expected text from the card itself, so the phone cannot spoof them.

### Card
```json
{ "id": "b007", "kind": "booking|info|correction|digits", "situation_bn": "...",
  "persona": {"relation": "son", "patient": "আরিফ"},
  "steps": [ { "id": "b007.who", "slot": "who|day|time|name|phone|confirm|open",
               "question_bn": "what the agent says", "audio": "q/<name>.wav" or "",
               "audio_name": "<name>", "hint_bn": "what the contributor wants (intent, not a sentence)",
               "expected_text": null, "facts": {} } ] }
```
`audio` is empty when the voice was not built: fall back to showing `question_bn` and, if available,
`speechSynthesis` with lang `bn-BD`. Never read `hint_bn` aloud.

## Staff endpoints (private app; header `Authorization: Bearer <token>`)

Roles: `reviewer`, `adjudicator`, `admin` (admin can also review and adjudicate).

| Method and path | Reply |
|---|---|
| `GET /api/review/me` | `{name, role, reviewed}` |
| `GET /api/review/next` | `{item: null}` or `{item:{clip_id, mode:"draft"\|"verify"\|"blind"\|"adjudicate"\|"seed", slot, kind, question_bn, duration_s, split, setting, draft, expected, candidates?, audio_url}}` |
| `POST /api/review/submit` `{clip_id, text, flags[], seconds}` | `{ok, text (cleaned), notes[], status}` or `{error: empty\|no_bangla\|already(409)}` |
| `GET /api/review/audio/{clip_id}?exp=&sig=` | audio (the signed `audio_url` from the queue; expires after 10 minutes) |
| `GET /api/admin/stats` | see `CollectorStore.stats()` + `reviewers[]` + `backlog` |
| `GET/POST /api/admin/campaigns` | list; create `{name, from_name, note}` -> `{code, path:"/?c=code"}` |
| `GET/POST /api/admin/staff`, `DELETE /api/admin/staff/{id}` | list; create `{name, role}` -> `{token}` (shown once) |
| `GET /api/admin/clips?status=&limit=&offset=` | `{clips:[{..., audio_url}]}` |
| `POST /api/admin/clips/{id}/remove` `{reason}` | `{ok}` |
| `POST /api/admin/settings` `{kill_switch?, goal_minutes?}` | `{ok}` |
| `GET /api/admin/audit?limit=` | `{events:[{at,actor,action,detail}]}` |

Review rules the UI must reflect: **mode `draft`** shows the machine draft to correct;
**`verify`** shows `expected` ("did they say this?" Yes / Fix); **`blind`**, **`seed`** and
**`adjudicate`** never show a draft (adjudicate shows `candidates`); flags are
`unusable`, `other_language`, `personal_details`, `offensive` (these reject the clip), and
`noisy`, `unclear` (kept). The server converts typed digits to Bangla words and keeps phone numbers
as digits (reply `text` and `notes`); show the cleaned text back.

## Non-negotiable UI requirements

1. **Bangla first**, with an English toggle for every string. Big buttons, high contrast, no
   horizontal scroll at 360 px, tap targets >= 44 px, `lang="bn"` on the document.
2. **No build step.** Plain ES modules, CSS and HTML under the static folders. No framework, no CDN,
   no external fonts or scripts (a strict CSP forbids them). Contributor page total weight < 100 KB
   gzipped excluding audio. System font stack that renders Bangla (`"Noto Sans Bengali", "Kalpurush",
   "Siyam Rupali", system-ui, sans-serif`).
3. **Server is the source of truth for what a clip answers**; the phone only sends ids.
4. **API base URL is configurable** so the page can be a static shell on another host:
   `window.SHEFA_API` (default `""`, same origin), read from a `config.js` loaded first.
5. Never put contributor secrets in URLs. Store the session (cid, secret, speaker ids, delete code,
   queue) in `localStorage`/IndexedDB inside try/catch; the page must still work without storage.
6. No tracking, no analytics, no third-party requests (except Cloudflare Turnstile when
   `turnstile_site_key` is set).
